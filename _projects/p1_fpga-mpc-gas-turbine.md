## Overview

This project investigates FPGA-based acceleration of Model Predictive
Control for gas turbine aero-engine applications.

The work focuses on implementing computationally intensive MPC algorithms
on FPGA hardware to enable high-speed and deterministic control suitable
for safety-critical aerospace applications.

## Objectives

- Develop an FPGA-based implementation of MPC.
- Investigate hardware/software co-design approaches.
- Integrate the controller with MATLAB/Simulink.
- Validate the implementation using hardware-in-the-loop testing.
- Evaluate computational performance for real-time aerospace control.

## My contribution

My work focuses on the design and implementation of the FPGA-based MPC
architecture, including algorithm development, hardware implementation,
and real-time validation.

## Technologies

**Hardware:** FPGA, ZCU102, Speedgoat

**Software:** MATLAB/Simulink, Vivado, Vitis, VHDL, HLS

## Outcomes

The project investigates the feasibility of FPGA acceleration for
computationally demanding MPC algorithms in real-time gas turbine control.
